## 📺 VGA Display
The VGA output visualizes the game state:
*   **Left Bar**: Player 1 Score (Color coded 0-4)
*   **Right Bar**: Player 2 Score (Color coded 0-4)
*   **Center**: Animated dash syncs with HEX display.
